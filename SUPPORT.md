# Support

SOMA is a portfolio/research project and public runtime source release.

Use GitHub Issues for:

- reproducible bugs
- focused feature requests
- documentation gaps
- research notes with cited evidence

Use GitHub Security Advisories for vulnerabilities:

https://github.com/wnsdy95/SOMA-Public/security/advisories/new

Before filing an issue, include:

```bash
soma diagnose
soma --version
rustc --version
```

Redact local paths, private project names, prompts, API keys, and local database
content unless they are essential to the report.
