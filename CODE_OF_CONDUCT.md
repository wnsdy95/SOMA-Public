# Code of Conduct

SOMA uses a simple contributor standard:

- be respectful and precise
- criticize ideas and code, not people
- assume good faith while asking for evidence
- keep research disagreements concrete and cited
- do not harass, threaten, or target contributors

Unacceptable behavior includes personal attacks, discriminatory language,
sexual harassment, doxxing, sustained disruption, or bad-faith security reports.

Project maintainers may remove comments, close issues, block users, or report
abuse to GitHub when needed to keep the project healthy.

For sensitive conduct or security concerns, use the private channels described
in `SECURITY.md`.
